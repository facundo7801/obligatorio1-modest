\section{Problema 1}

\subsection{Simulación de una muestra}

Se considera la densidad

\[
f_X(x;\theta)=\frac{1}{2}(1+\theta x),
\qquad -1\leq x\leq1,
\qquad -1\leq\theta\leq1,
\]

y se desea simular una muestra tomando $\theta=-1/3$. En este caso,

\[
f_X(x)=\frac{1}{2}\left(1-\frac{x}{3}\right).
\]

Para generar la muestra se utilizó el método de aceptación-rechazo, tomando como
densidad propuesta una distribución uniforme en $[-1,1]$:

\[
g(x)=\frac{1}{2}.
\]

La constante utilizada es $M=4/3$, por lo que un candidato
$x\sim U(-1,1)$ se acepta si

\[
u\leq
\frac{f_X(x)}{Mg(x)}
=
\frac{3}{4}\left(1-\frac{x}{3}\right),
\qquad u\sim U(0,1).
\]

El procedimiento se repite hasta obtener $n$ observaciones aceptadas.

Para una muestra de tamaño $10$ se obtuvo, por ejemplo,

\[
\begin{split}
x = (&0.0523,\,-0.7548,\,-0.7058,\,-0.3231,\,
0.0924,\,0.2595,\\
&0.7691,\,-0.1610,\,0.3569,\,-0.1851).
\end{split}
\]


\subsection{Estimador de máxima verosimilitud}

Para una muestra $x_1,\ldots,x_n$, la función de verosimilitud es

\[
V_n(\theta)
=
\prod_{i=1}^{n}f_X(x_i;\theta)
=
\frac{1}{2^n}
\prod_{i=1}^{n}(1+\theta x_i).
\]

Para evitar trabajar directamente con el producto se utilizó el negativo del
logaritmo de la verosimilitud:

\[
\ell_n(\theta)
=
-\log V_n(\theta)
=
n\log(2)
-
\sum_{i=1}^{n}\log(1+\theta x_i).
\]

El estimador de máxima verosimilitud se obtiene minimizando esta función en
$[-1,1]$:

\[
\hat{\theta}
=
\underset{-1\leq\theta\leq1}{\operatorname{arg\,min}}
\;\ell_n(\theta).
\]

Para realizar la minimización numérica se utilizó el algoritmo de
\textit{Golden Search}.

Para la muestra de tamaño $10$ obtenida anteriormente se obtuvo

\[
\boxed{\hat{\theta}=-0.2964}.
\]

Al aumentar el tamaño de la muestra, se observa una disminución
considerable de la varianza del estimador y, en consecuencia, del MSE.
Además, el sesgo se aproxima a cero. Esto indica que las estimaciones
de $\hat{\theta}$ se concentran cada vez más alrededor del verdadero
valor $\theta=-1/3$. Para $n=100$ y $n=1000$, el término
$\operatorname{Sesgo}^2$ es muy pequeño, por lo que el MSE coincide
con la varianza al redondear a cuatro decimales.
